SanskyStream 1.0.0 — 2026-09-26
---------------------------------

INITIAL RELEASE

Windows Application (M1-M17)
  + Win32/Direct3D 11 application foundation
  + TCP server receiver (port 5000) for control and audio
  + UDP receiver (port 5001) for low-latency H.264 video
  + Media Foundation H.264 hardware-accelerated decoder
  + Direct3D 11 NV12 texture renderer with aspect-ratio preservation
  + Media Foundation AAC-LC audio decoder
  + WASAPI event-driven audio playback
  + A/V synchronization engine (M12)
  + Low-latency pipeline: TCP_NODELAY, single-slot frame queue,
    bounded audio buffer, no unnecessary frame copies (M13)
  + OBS Studio plugin (sansky-source.dll) via shared memory (M14)
  + mDNS/DNS-SD device discovery — _sanskystream._tcp (M16)
  + Platform badge UI: [iOS] / [Android] device identification
  + Settings: manual IP entry, discovery toggle (M17)

iPhone / iOS (M3-M10)
  + ReplayKit broadcast extension for screen capture
  + VideoToolbox H.264 encoder
  + UDP H.264 video transport with fragment reassembly
  + AVAudioEngine microphone + system audio capture
  + AudioToolbox AAC-LC encoder
  + TCP audio transport
  + Bonjour mDNS service advertisement

  STATUS: Source complete. Physical end-to-end testing PENDING.
